# KardsAFK4EXP · 修复版

> KARDS（二战卡牌游戏）自动挂机脚本 —— 图像识别 + 键鼠模拟，不进内存、不改客户端、不抓包。

本仓库基于上游 `KardsAFK4EXP` 整理修复而来。上游脚本能跑，但存在一个**会让脚本静默永久停摆**的致命缺陷和若干崩溃/满核空转问题，本仓库逐个修掉并补齐了日志与自测。

## 它是什么 / 不是什么

| | 说明 |
|---|---|
| ✅ 是 | 一个**挂机刷经验**的宏：认按钮 → 点按钮 → 4 分钟投降 → 下一局 |
| ❌ 不是 | 一个会打牌的 AI。它不认识费用、不认识卡牌效果、也不区分「部署单位」和「攻击目标」 |

上游的设计目标就是**把对局拖满 4 分钟拿经验**（赢局超过 4 分钟经验不再增长），而不是赢。所以后面出牌的胜率会很低——这是有意为之，不是 bug。想让它真会打牌，见 [docs/逻辑解读.md 的重构路线](docs/逻辑解读.md#七若要真的会打牌重构路线)。

## 快速开始

```bat
:: 1. 安装依赖（首次）
python -m pip install -r requirements.txt

:: 2. 双击运行（会自动检查依赖）
start.bat
```

或者直接 `python kards.py`。

### 运行前提

1. **游戏分辨率固定 2220×1271**，窗口化或无边框窗口。分辨率不符会警告并可能识别错位。
2. 游戏内语言设为**中文**。
3. 若要使用「断线自动重启游戏」功能，需要安装 KARDS **官方启动器**，且启动器语言设为**英文**。
4. 首次运行前把对局界面切到**主菜单**，脚本会自己往下走。

> **急停**：把鼠标快速甩到屏幕**左上角**即可触发 PyAutoGUI 的 FAILSAFE 中止脚本。也可以用 `Ctrl+C`。

## 修复了什么（摘要）

| # | 原版问题 | 后果 |
|---|---|---|
| 🔴 1 | 投降时找不到投降按钮 → `pyautogui.click(None)` 抛 `TypeError`，线程死掉但暂停标志永远停在 `True` | **主循环永久卡死，挂机一夜等于白挂** |
| 🔴 2 | 每次点「确认」都新起投降线程 | 线程堆叠互相抢鼠标，拖拽错位 |
| 🔴 3 | `clickedstartBattle.png` 未判空就点击 | 模板匹配失败即崩溃 |
| 🟠 4 | 两处 `while` 轮询无 `sleep` | 单核跑满 + 高频全屏截图 |
| 🟠 5 | `region` 参数把右下角坐标当宽高传入 | 识别区域放大 4 倍，**把手牌区框进战场区**，误把手上单位当场上单位 |
| 🟠 6 | 等待「对手回合」无超时 | 对面卡死/拔线时脚本永久挂住 |
| 🟡 7 | `locateAllOnScreen` 边迭代边点击 | 点击后坐标失效，重复点错目标 |
| 🟡 8 | 主循环无异常兜底 | 任何一次异常都让脚本退出 |
| 🟡 9 | `logging` 导入未使用 | 出问题只能肉眼盯屏幕，无任何记录 |

完整的「现象 → 根因 → 修复」见 **[CHANGELOG.md](CHANGELOG.md)**。

## 工作原理（简版）

```
main()  主线程：无限循环的「扫描器」
  ├─ start_game_out()      点官方启动器上的「开始游戏」
  ├─ daily_mission()       点掉每日任务红点
  ├─ main_menu()           修正主菜单选中态
  ├─ restart()             断线后点「重启」
  ├─ exit_game()           点「退出」
  ├─ click_pass_button()   轮到我方 → play_cards() → 空过/结束回合 → 等对手
  ├─ _handle_result_screens()  结算 → 继续/领奖/关广告/离开战场回顾
  └─ click_start_game_button() 主菜单 → 匹配 → 人机对战 → 确认

surrender()  后台线程：点确认开跑，240 秒后自动投降
```

它不是状态机，而是**每轮把所有已知按钮都试一遍**，谁在就点谁，找不到就靠 `pass` 兜底。实现简单，但误点风险偏高 —— 重构方向见 [docs/逻辑解读.md](docs/逻辑解读.md)。

完整的逐函数拆解、坐标系推导、以及出牌逻辑的真实策略，都写在这里：**[docs/逻辑解读.md](docs/逻辑解读.md)**。

## 配置项

全部集中在 `kards.py` 顶部「配置区」，改坐标/时序不用再全文搜索：

| 常量 | 默认值 | 说明 |
|---|---|---|
| `SURRENDER_ENABLED` | `True` | 是否启用 4 分钟自动投降。关掉更"像人"但升级效率暴跌 |
| `SURRENDER_DELAY` | `240` | 开局后多少秒投降（4 分钟经验封顶） |
| `BOX_MINE` | `(501,733,1704,988)` | 我方支援阵线识别区，**(x1,y1,x2,y2) 语义** |
| `BOX_ENEMY` | `(437,150,1760,397)` | 敌方支援阵线识别区 |
| `HAND_CARD_X0/DX/COUNT` | `800 / 100 / 6` | 手牌盲打的点击位置与张数 |
| `CONF_STRICT / CONF_LOOSE` | `0.90 / 0.70` | 场上单位 / UI 按钮的匹配置信度 |
| `HUMANIZE` | `True` | 点击加随机抖动与随机耗时，降低机械特征 |
| `WAIT_CONFIRM_TIMEOUT` | `120` | 等「确认」按钮的超时（秒） |
| `WAIT_OPPONENT_TIMEOUT` | `180` | 等对手回合的超时（秒） |

> ⚠️ `BOX_*` 必须是 **(x1, y1, x2, y2)**，也就是「左上角 + 右下角」。代码里由 `to_region()` 转成 pyautogui 需要的 `(x, y, width, height)`。**不要直接把 pyautogui 的 region 格式填进来**，这正是上游最隐蔽的那个 bug。
